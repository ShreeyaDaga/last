CHECK VS CODE - 

Press:
Ctrl + Shift + P

Search:   Java: Configure Java Runtime

Under Installed JDKs, make sure it points to Java 8.
Example path:  /usr/lib/jvm/java-8-openjdk-amd64

If not present, add it.




SET JAVA_HOME PROPERLY

Open terminal:
nano ~/.bashrc

Add at bottom:
export JAVA_HOME=/usr/lib/jvm/java-8-openjdk-amd64
export PATH=$JAVA_HOME/bin:$PATH

Save and run:
source ~/.bashrc

Verify:
echo $JAVA_HOME
